# 리뷰어 초대문 및 평가 방법 (한국어)

## 초대문 (한국어 원어민에게 보내는 메시지)

안녕하세요! 저희는 중국 광고 카피를 해외 시장에 맞게 현지화하는 AI 도구를 만들고 있어요. 번역의 자연스러움을 판단해 주실 원어민 분이 필요합니다.

한국어로 된 짧은 광고문이 약 24개 정도 있어요. 각각에 대해 3가지 질문에 답해 주시면 됩니다. 소요 시간은 약 10분이고, 클릭만 하면 돼요.

'명백히 어색하다' '문화적으로 위화감이 있다' '불쾌하다'고 느끼는 부분이 있으면 선택 사항인 댓글란에 적어 주시면 큰 도움이 됩니다.

감사합니다!

## 평가 방법 (리뷰어에게 보여줄 내용)

각 샘플은 짧은 광고문입니다. 각각에 대해 답해 주세요.

**Q1. 이 광고는 한국인이 쓴 것 같아요, 아니면 번역인 것 같아요?**
- 한국인이 쓴 것 같다
- 번역인 것 같다
- 잘 모르겠다

**Q2. 자연스러움을 1~5점으로 평가해 주세요**
- 1 = 명백한 기계 번역 / 어색함
- 5 = 완전히 자연스럽고 실제 광고에서 볼 수 있는 수준

**Q3. 광고라면, 이 제품을 더 보고 싶나요?**
- 네
- 아니요

**선택 사항:** 이상한 표현, 한국 시장에 안 맞는 표현, 불쾌한 표현이 있으면 댓글란에.

## 팀용 메모 (리뷰어에게 보내지 않음)
- 각 리뷰어는 자기 시장 샘플만 본다.
- 1샘플=1행. ID는 S001~S036으로 셔플·비식별화됨. 판정 완료 전까지 어느 것이 어느 것인지 공개하지 않는다.
- 1인당 최대 20샘플 (피로도 대비).
