# レビュー依頼文・評価手順（日本語）

## 依頼文（日本語ネイティブの方へ送る文言）

こんにちは！私たちは、中国の広告コピーを海外市場向けにローカライズするAIツールを開発しています。翻訳の自然さを判断してくれるネイティブスピーカーの方が必要です。

日本語の短い広告文が約24個あります。それぞれについて、3つの質問に答えてください。所要時間は約10分です。入力はクリックだけでOKです。

「明らかに不自然」「文化的に違和感がある」「不快に感じる」という箇所があれば、任意のコメント欄に書いていただけると大変助かります。

ご協力ありがとうございます！

## 評価手順（レビューアーに見せる内容）

各サンプルは短い広告文です。それぞれについて次に答えてください。

**Q1. これは日本人が書いた広告だと思いますか？それとも翻訳だと思いますか？**
- 日本人が書いた
- 翻訳だと思う
- わからない

**Q2. 自然さを1〜5で評価してください**
- 1 = 明らかに機械翻訳 / ぎこちない
- 5 = 完全に自然で、実際の広告で見かけるレベル

**Q3. 広告だとすると、この商品をもっと見てみたいと思いますか？**
- はい
- いいえ

**任意項目：** 変だと思う表現、日本市場に合わない表現、不快な表現があればコメント欄に。
