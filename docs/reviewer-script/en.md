# Reviewer Invitation & Instructions (English)

## Invitation message (send to native English speakers)

Hi! I'm part of a team building an AI tool that localizes Chinese ad copy for overseas markets. We need native speakers to tell us which translations sound natural.

You'll see ~24 short ad texts (in English). For each one, answer 3 quick questions. It takes about 10 minutes. No writing needed — just click.

If anything reads as obviously wrong, culturally off, or offensive, there's an optional comment box — that helps us a lot.

Thanks so much for helping us test this. 🙏

## Instructions (what the reviewer sees with the sample list)

Each item is a short ad text. For each one, answer:

**Q1. Do you think this was written by a local person, or is it a translation?**
- Written by a local person
- It's a translation
- Not sure

**Q2. How natural does it sound? (1–5)**
- 1 = obviously machine-translated / robotic
- 5 = completely natural, like something you'd see in a real ad

**Q3. If this were an ad, would you want to keep looking at the product?**
- Yes
- No

**Optional:** Anything that sounds weird, wrong for the US market, or offensive? Drop it in the comment box.

## Notes for the team (not sent to reviewers)
- Each reviewer sees only the samples for their own market.
- One sample = one row. Sample IDs are S001–S024, shuffled and de-identified — do NOT reveal which is which until judging is done.
- Cap reviewers at 20 samples each to avoid fatigue.
