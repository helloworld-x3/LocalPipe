# LocalPipe 当前学术与技术创新（阶段性证据）

## 研究问题

在同一基座模型、同一源广告和同一目标市场下，加入国别文化画像与分层质量控制，是否比裸 Prompt 直出更自然、更像当地人创作，同时不损害广告吸引力？

## 项目主体：补齐素材生成工具前面的创意决策层

LocalPipe 的主体不是质检。质检只是防止错误进入交付的护栏。真正要补齐的是素材生成工具通常不负责的上游问题：这个国家应该主打哪个卖点和情绪，中国创意中的文化表达在当地应替换成什么，以及一条中文 brief 如何变成可执行的当地创意 brief。

```text
中国创意/brief → 国别市场创意策略 → 本地化文案与素材指导包
→ KreadoAI 等工具生成图片/视频 → 审核反馈 → 更新市场画像
```

## 技术创新

1. **市场创意策略生成**：先解构卖点、情绪钩子、受众和 CTA，再根据国别画像重新决定卖点顺序、场景和行动号召。
2. **创译而非翻译**：文化载体、语气和平台表达在目标市场重新创作，保留营销功能而不是逐句转换。
3. **下游可执行交付**：输出市场创意策略、中文回译、适配说明、目标人群/平台标签、镜头方向和时长，并由 `kreado_adapter.py` 生成可复制Prompt与结构化JSON，形成可直接交给 KreadoAI 的创意输入。
4. **保真闭环回检**：由程序从结构化 checks 重算回收率，不接受模型自报分数；缺项、重复项、错误类型和非布尔值都会阻断通过并触发重做。该"不信任单点、以结构化核对为准"的思路与 COMET/BLEURT 类神经质量评估指标同源——后者以语义相似度自动评估翻译质量，本方案则按广告要素（卖点/情绪钩子/CTA/品牌保护术语）逐项核对，实现营销功能层面的可解释性校验，而非逐句语义打分。
5. **画像可追溯与可学习**：画像条目带 ID、来源、置信度、时效；产出记录 `used_entries` 和 profile trace，审核反馈可定位到具体条目并形成修订候选。
6. **A/B 严格配对**：LocalPipe 与裸 Prompt 使用相同创意和市场；任一侧失败则整对剔除，避免不完整样本影响盲测。
7. **飞书协作闭环**：飞书承载任务下发、审核和反馈归纳，LocalPipe 承载生成和质检，形成从创意到下一轮知识更新的工作流。

## 已有证据

- 四层管线已实现；
- 法国 Meta 服饰三变体样板已按真实 `localize()` 运行，韩国版本保留为备用；
- 71 项离线行为测试通过，当前覆盖核心管线、A/B配对、市场洞察、创意策略、证据追溯、语言资产、质量报告和 KreadoAI Brief 契约；
- 真实母语者数据仍在回收，当前不能声称 LocalPipe 已在统计意义上优于裸 Prompt。
- 法国画像的公开证据已记录 publisher、URL、摘录、证据等级和检索时间；没有具体来源的数字已降级为待验证研究问题。

## 今晚可以向教练展示

- 一条广告从中文创意到目标市场创意方案的完整过程：卖点重排、文化替换、本地化文案和下游素材指导字段；
- 一条广告的四层处理日志和质检结果（作为护栏，而不是项目全部）；
- 一个“needs_review”失败样例及其打回原因；
- 飞书任务表、结果表、审核表的字段设计；
- 从审核反馈定位画像条目并产生修订候选的闭环设计。
