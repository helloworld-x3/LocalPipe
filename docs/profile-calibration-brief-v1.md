# 画像校准任务 Brief — 视频语料校准

**发给**：孙文洁（画像库负责人）
**来源**：乔唯一（团队协调）· 2026-07-30
**前置**：`docs/experiment-design.md` 已排期母语者盲测；本任务是母语者校准前的**低成本预热校准**，用真实广告案例先修正 LLM 冷启动画像里明显可疑的条目

---

## 一、为什么做这件事

`profiles/jp.json` 和 `profiles/th.json` 目前是 **v0.1 冷启动版**，全部条目来源标注"LLM冷启动"，置信度最高只有"高"，且其中高置信度条目主要靠"公开资料交叉验证"——但**没有任何真实广告案例的直接引用**。

企业遴选/集训阶段评委如果翻画像库，第一个问题就是："这些条目你凭什么这么写？" 现在 `source` 字段里写的是"LLM冷启动"，经不起问。用真实广告案例校准后，`source` 能写成"日本真实广告案例（av204820911）"，这是可追溯的证据。

## 二、校准目标

### 目标 1：验证/修订 jp-003（语言风格，置信度=中）

**现有条目**：
> 广告语偏好含蓄、留白，靠氛围与细节打动而非直给卖点；敬体（です/ます）为默认……拟声拟态词是地道感的重要来源

**校准素材**：B站 av11031205「日本广告绿茶，心机，撩」+ av204820911「东京瓦斯拟人创意广告」

**校准动作**：
- 看完回答三个问题：① 含蓄留白是否成立？② 拟人化手法（东京瓦斯把公司拟人成角色）是否值得新增为创意手法条目？③ 有没有与现有条目矛盾的表达方式？
- 结论写入 `profiles/jp.json`：
  - 如果成立 → `confidence` 从"中"升"高"，`source` 加真实案例
  - 如果不成立 → 修订 content，保留置信度，更新 source

### 目标 2：验证/修订 th-003 和 th-005（泰国风格，置信度=中/高）

**现有条目**：
> th-003：泰国消费者吃软萌、自嘲式幽默，不吃讽刺和攻击性幽默
> th-005：视觉偏好高饱和度；广告叙事偏爱反转剧情和夸张表演

**校准素材**：B站 av845587800「虾皮泰国市场特点」

**校准动作**：视频讲泰国市场特点，重点核对 th-006（促销敏感度/COD）和 th-003（幽默风格）是否与实际一致，差异记入修订。

### 目标 3：盲测对照组素材（可选，不阻塞）

B站 av564957274「2022十大优秀广告文案」→ 作为盲测"专业文案基准"候选素材，先收藏，具体用在实验设计定稿时再说。

## 三、产出格式（必须对齐现有 JSON 结构）

`profiles/jp.json` 现有结构：
```json
{
  "id": "jp-003",
  "type": "语言风格",
  "content": "…",
  "confidence": "中",      // 校准后可改"高"
  "expires": "2026-12-31",
  "source": "LLM冷启动"    // 校准后改为"LLM冷启动+真实广告案例(av204820911)"
}
```

新增条目（如日本拟人化手法）：
```json
{
  "id": "jp-008",
  "type": "创意手法",
  "content": "日本品牌广告常用拟人化/角色化叙事（品牌虚拟形象、吉祥物），将抽象服务具象为角色互动",
  "confidence": "中",
  "expires": "2027-01-01",
  "source": "真实广告案例(av204820911东京瓦斯拟人广告)+LLM交叉验证"
}
```

## 四、完成标准

1. `profiles/jp.json` 至少修订 1 条 + 新增 1 条（拟人化手法）
2. `profiles/th.json` 至少验证 2 条（th-003 或 th-005/th-006）
3. 跑通验证：
   ```bash
   python -c "import json; [json.load(open(f'profiles/{m}.json', encoding='utf-8')) for m in ['japan','thailand']]"
   ```
   确认 JSON 不破坏
4. 跑 `python test_pipeline.py` 确认管线回归通过

不阻塞任何节点，开学前完成即可。母语者校准仍是正式方案，这次只是把能做的先做了。
