## 三、方案核心

**不是翻译工具，是创译（Transcreation）管线。**

现有 AI 本地化工具只做形式转换（翻译→配音→字幕），同一条创意换语言铺多国，本质一稿多投。LocalPipe 把创意拆成内核（卖点/情绪钩子/文化梗/CTA），基于国别文化画像**重新创作**，让产出「像当地人写的」。

**四层管线架构：**

```
中文创意 → [1]解构层 → [2]重创作层(画像+品牌规则) → [3]保真回检(交叉核对+打回) → [4]禁忌质检 → 交付
```

**差异化机制（GitHub 上无同类）：**
1. **保真闭环回检**：程序交叉核对源要素 vs LLM 自检清单（非信任 LLM 自报值），缺项/重复/非 bool 不过，打回重做
2. **画像条目元数据化**：置信度/时效/来源/ID，过期条目自动退场
3. **画像引用追溯（used_entries）**：产出出问题直接定位到具体画像条目

## 六、关键设计决策

1. **A/B 严格配对**：同一 creative_id + market 的 A/B 必须同时进或同时出盲测，任一边失败则整对跳过（记录到 skipped）
2. **保真率程序重算**：`is True` 严格判断，字符串 `"false"` 不会绕过；且按要素类型**加权**（品牌词/数字事实=3、卖点=2、情绪/CTA=1），漏数字比漏情绪扣分重
3. **fidelity 结构校验**：不仅看回收率，还检查是否缺项/重复/非 bool
4. **pass 五条件**：回收率达标 + 结构完整 + 禁忌低风险 + used_entries 全有效非空 + 无无效/禁忌画像引用
5. **安全分层**：XML 结构隔离是风险降低而非安全边界（已在 SECURITY.md 中澄清）
6. **cache key 含 base_url**：防止不同 API 端点响应串号
