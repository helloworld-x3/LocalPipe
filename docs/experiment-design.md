# 法国母语者 A/B 验证方案

Hello World · LocalPipe · Meta + 服饰 + 法国主样板

## 1. 验证目标

在同一基座模型、同一中文广告 Brief 和同一目标市场下，对比：

- Baseline：裸 Prompt 直接生成；
- LocalPipe：创意解构 → 法国画像重创作 → 加权保真回检 → 禁忌质检。

验证 LocalPipe 是否在法语自然度、本地原创感和广告吸引力上提供正向信号，同时记录发布可用性与文化/合规风险。当前实验定位为小样本方向性验证，不做统计显著性或 ROI 宣称。

## 2. 样本设计

- 目标市场：法国；
- 平台：Meta；
- 品类：服饰；
- 中文广告：3 条；
- 每条生成 Baseline 与 LocalPipe 两个版本，共 3 组 A/B 配对；
- 其中 2 条为主质量样本，1 条为身材/体重宣称安全案例；
- A/B 版本随机标记为 X/Y，评审前不显示生成方法；
- 任一侧生成失败、文案为空或状态为 `error` 时，整对剔除，不允许单边进入评审。

安全案例不并入主质量平均分，单独观察系统能否识别并阻断不适合发布的表达。

## 3. 母语者任务

每组 X/Y 只回答少量问题：

1. 哪个版本更像法国本地人写的？
2. 哪个版本读起来更自然？
3. 哪个版本更像值得继续看的 Meta 广告？
4. 分别判断 X/Y 的发布可用性：原样发布、小幅修改、大幅修改、不可发布；
5. 如有明显问题，指出问题版本与原因。

建议评审者为法国法语母语者；记录评审者是否长期生活在法国、是否接触电商或广告，但不收集不必要的身份信息。

## 4. 揭盲与统计

评审完成后使用私有 blind key 揭盲。`experiment_metrics.py` 负责：

- 计算 Q1/Q2/Q3 的 LocalPipe 胜、Baseline 胜、平局和无效票；
- 计算非平局胜率：`LocalPipe 胜 / (LocalPipe 胜 + Baseline 胜)`；
- 计算两组的发布可用率；
- 把主质量样本与安全案例分开；
- 保留无效样本和结论边界。

当有效评审者很少时只报告原始计数和方向性信号，不使用“显著优于”“提升百分之多少”等表述。

## 5. 当前状态

- 已完成法国 3 条广告 A/B 问卷设计；
- 已收到 1 份法国法语母语者真实反馈；
- 另一份反馈仍在回收；
- 当前只能说明项目进入真人验证阶段，不能宣称 LocalPipe 已优于 Baseline；
- 收齐后统一揭盲、统计并决定是否校准品牌写法、画像条目和 Prompt。

## 6. 失败条件与迭代

- LocalPipe 没有稳定优势：检查画像是否过度概括、创意路线是否同质化、保真门是否只保留信息却损伤自然度；
- 品牌名处理不自然：将反馈记为语言资产候选，至少两条独立证据或品牌方确认后才升级为正式规则；
- 安全案例未被拦截：优先修复禁忌画像或发布门控；
- 评审意见冲突：保留分歧，不用单人偏好覆盖正式画像；
- 样本不足：如实标为 pilot，比赛材料只展示方法、原始反馈和已验证的工程行为。
