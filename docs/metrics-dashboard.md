# LocalPipe 效果指标面板

> 定位：服务作品文档"可落地的效果"（教练五问第⑤问）。六项指标把"AI 看起来不错"转成"质量、风险、效率可以被测量"。
> 数据口径：**所有数字标注来源与样本量**。样本不足处明示"待补"，不做无依据宣称。文中 n=153 是此前筛选出的真实 LLM 调用历史快照，不是当前本地遥测文件的行数；当前 `.cache/telemetry.jsonl` 同时含测试、缓存和本地运行记录，刷新前必须按来源筛选，不能直接把总行数当企业样本。

## 1. 加权保真率

**定义**：程序按要素类型重算的保真率，不信任 LLM 自报。权重：品牌保护词与含数字的产品事实 = 3，核心卖点 = 2，情绪钩子与行动号召 = 1。公式：`Σ(权重 × 保留) / Σ(权重)`。

**当前值**：
- fashion demo：0.92（未加权 0.86）——丢失的是低价值情绪词，加权后损失变小。
- coolclip demo：1.00——数字事实"3 秒降温 15 度"完整保留。

**为什么这样设计**：漏掉一个数字事实比少一个情绪词严重得多。数字卖点丢失时加权率明显低于简单平均（例：`3秒降温15度` 丢失 → 0.40 vs 0.50），品牌词丢失同理。它把"广告业务直觉"编码进质检，而不是对所有要素一视同仁。

**待补**：批量运行后按市场汇总，给出分布而非单点 demo。

## 2. 风险拦截率

**定义**：不适合发布的表达是否被识别。两条证据链：
- **案例**：CoolClip"3 秒降温 15 度"在法国画像下触发 fr-002 定量功效宣称禁忌 → needs_review。C04"瘦十斤"身材宣称同样被拦截。
- **统计快照**：此前筛选的真实调用历史中约 39.2% 进 needs_review（保真/禁忌/画像引用任一未过即进），3.9% error。当前本地遥测混有测试和缓存记录，待按来源重算。**LocalPipe 不直接放行，多一层人工复核门**——这是工程分流设计，不等于正式投放拒审率。

**待补**：禁忌条目命中分布（fr-002 占比 vs 其他）；正式投放拒审率（当前无投放数据，ROI 列为后续目标）。

## 3. 母语者胜率

**口径**：非平局胜率 `W = LocalPipe 胜 / (胜 + Baseline 胜)`，平局剔除。样本少不做显著性宣称。

**当前**：已回收两位独立法国法语母语消费者反馈。揭盲后的有效非平局判断为 LocalPipe 9、Baseline 8，非平局方向比例约 52.9%。这是问题级判断的汇总，不是 9 人对 8 人；样本量不足，不做显著性检验，也不写“LocalPipe 整体优于 Baseline”。

分案例看，FR01 提供 LocalPipe 正向信号；FR02 明确暴露产品类型漂移；FR03 作为安全案例单列，不并入主质量平均。当前实验最有价值的结论是系统能通过真人反馈发现具体缺陷并驱动复测。

## 4. 发布可用率

**定义**：问卷 Q4 中"原样发布（A）+ 小幅修改（B）"占有效评价的比例。

**当前值**：不计算。Q4 规范要求只能填写 A/B/C/D，但回收数据中存在 X/Y 等无效代码，且部分汇总字段有歧义。原始答案保留，并在数据表中记录 `validity/reason`；不能用这些字段计算正式发布可用率。

**待补**：评审量扩大后给出 C/D 比例；记录真实人工修改分钟数，计算时间节省率 `(T人工 − T LocalPipe) / T人工`。

## 5. 平均处理时间

**口径**：真实 LLM 调用（排除缓存命中，缓存会把均值拉成假数字）。中位比均值更代表"正常调用"——均值 15.3s 被 204s 的异常调用拉高。

**历史快照**（筛选 n=153）：中位 **8.4s**，p90 22.9s。分层：解构 1.3s / 重创作 5.4s / 保真回检 2.2s / 禁忌 1.1s。该指标是工程代理指标，不是 ROI 或投放效果。

**证明什么**：一次四层管线（含打回重试闭环）8 秒级完成——人工创作一条本地化广告通常以小时计，素材生产环节以此为基准。

**待补**：与人工基线对比的实测记录（找测试者实际计时，不估算）。

飞书真实任务运行后执行：

```text
python feishu_connector.py --export-metrics outputs/feishu_business_metrics.json
```

导出只统计审核表中明确填写的配对数据：AI 总耗时、人工审核分钟数、人工从头完成基线分钟数。任一字段缺失，该条不会进入时间节省统计，避免用估算值冒充企业实测。

## 6. 画像置信度变化

**定义**：画像不是写死的知识库，而是带元数据的可校准证据系统。fr 条目含 `evidence_level`（A 权威源 / B / C 冷启动假设）、`validation_status`、`unverified_claims`、`expires`。

**当前值**：
- fr 画像 v0.1 → v0.2（2026-08-08），10 条条目。
- fr-002（法国广告避免体重/数字功效宣称）：evidence_level A（ARPP 官方规则引用）+ **两位母语者独立定性支持**——FR03 两位评审都指出 “-5 kg” 宣称不适合法国广告，与管线拦截结论一致。

**为什么重要**：这是“系统能按反馈迭代”的证据。当前只有 n=2 的定性支持，仍标记为探索性校准信号，不能外推为法国消费者总体事实。

## 附录：如何刷新本面板

处理时间 / 风险分流：`python stats.py` 或直接读 `.cache/telemetry.jsonl`，先按真实调用来源过滤；`stats.py` 默认只看最近 20 条，不能直接用于企业效果结论。
demo 保真率：`python generate_demo_fr_fashion.py && python generate_demo_fr_coolclip.py`（命中缓存，不新增 LLM 花费）。
画像元数据：`profiles/fr.json`。
母语者问卷：匿名原始问卷和私有揭盲 key 留存；公开材料只报告去标识汇总、无效字段和结论边界。
